# Gmpd

<p align="center">
  <img src=".github/logo.png" alt="mono-gtk-gmpd logo" width="128" />
</p>

A Mono GTK# client for MPD, the Music Player Daemon.

## What it does

It connects to and disconnects from an MPD server and sends playback commands
using an MPD client connection class.

## Tech

- C# with Mono and GTK#
- MPD

## Building

Open the `.sln` file in MonoDevelop, or build it with Mono and run the resulting
`.exe` with `mono`. Requires GTK# 2.
